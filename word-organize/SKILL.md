# Word 文档排版整理

整理已有 DOCX 时，以用户的用途、模板和明确要求为准。保留原文及其含义，只修改约定的格式；只有用户允许增加文字时，才依据内容补充缺失的图题或表题。未经要求不重写正文、不编造图注或数据来源。

## 先检查，再设置样式

1. 明确源文件和交付位置，检查是否有用户指定模板、字体、字号或学校格式。确认文件当前版本，保留原稿或在副本上工作；不要覆盖用户同时编辑的内容。用目标应用检查页面、正文、表格、图片、页眉页脚、目录、公式及已有样式。
2. 用户指定 WPS MCP 时，使用 WPS MCP 打开和编辑；先通过工具发现其实际操作、路径和参数。若不支持某操作或工具不可用，说明限制，采用可验证的替代方式。WPS 保存超时时，先检查文档状态和磁盘文件，不要盲目重复写入。
3. 用命名样式组织总标题、章标题、节标题、正文、图示、图题、表题、图注、表注、表格正文、公式、代码及参考文献。标题保留文档的大纲级别；图题在图下、表题在表上，注释放在所属图表附近。仅为实际需要创建和应用样式。保持原有编号、引用、目录字段和语义。
4. 依据用户指定的字体分别设置中文及西文字体，并检查粗体、字号、颜色、行距、段前段后、首行缩进和对齐。用户没有给模板时可选用常见文书字体：中文正文宋体、标题黑体，西文 Times New Roman；这些只是可调整的默认方案。公式符号、上标下标和英文必须能够正确显示，不能因统一字体而变成方框。
5. 修改样式后检查直接格式、字符样式和主题字体是否覆盖了它。不要给全文逐段强加直接字体以冒充可维护样式；对实际阻碍统一修改的覆盖做范围明确的清理，保留有意义的粗体、上下标等。选一份临时副本修改一个样式，确认已使用该样式的段落随之变化，再丢弃测试副本。

## 图表与分页

- 尊重现有图片及用户明确要求；不要重绘原图，也不要为了统一格式擅自改变浮动对象或锚点。若要求图片不变，保留图片数据、裁剪、尺寸、锚定和相对位置；优先调整段落与分页。位图内的文字属于图片，修改 Word 字体不能改变它；若用户要求原图不变，交付时说明这一边界。
- 对嵌入型图片，图片段落使用自动或合适的行距，避免固定行距把图裁成细线。居中排版时检查首行缩进；合理设置与下段同页，使图题紧随图片，表题与表格相邻；不能保证时调整分页，若用户允许调整图片尺寸则保持原有比例，不拉伸图形。
- 表格单元格内容应完整，检查行列、对齐、边框、跨页、表头和行高。长路径、网址和代码在两端对齐下可能导致字间距异常，应使用适当的左对齐样式或换行，不改变路径文本。
- 控制标题孤行、图片被裁切、表格跨页、代码或公式溢出、空白页、页眉页脚以及孤立图题。样式设置后还要查看实际渲染效果。

## 验证与交付

- 在目标编辑器中保存并重新打开；使用其预览或导出 PDF 逐页检查，兼顾目标应用和必要的兼容性渲染。核对正文、图表数量、图像嵌入或锚定方式、表格结构及引用是否保留；重新排版后页数允许变化，要检查内容无遗漏。重点放大检查图片、复杂表格、公式和页面边缘。仅解析 DOCX 文件结构不能代替目视检查。
- 检查正文和实际使用的样式的字体，包括中西文字体、主题和直接格式；不存在的字体可能被替换。若必须用底层 DOCX 修复编辑器无法设置的样式，先保存并关闭编辑器、在副本操作、保护文本与媒体，再重新打开并验证，避免覆盖编辑器中的未保存改动。
- 交付清楚标注的成品，说明使用的命名样式、保留的原稿和未能核验的限制。不要声称所有格式或原图内部字体已修复，除非确实检查到。
